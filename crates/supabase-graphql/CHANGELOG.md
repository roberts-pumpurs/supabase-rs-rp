# Changelog

## 0.1.0

- Add a Supabase GraphQL client with buffered variables, operation names, custom headers, raw responses, and typed data.
- Preserve partial data, execution errors, locations, typed paths, and extensions; distinguish transport/HTTP/decode failures.
- Protect default credential forwarding with same-origin redirects and sensitive headers; support user tokens and explicit POST retry opt-in.
- Add mock protocol tests and opt-in local mutation/readback/RLS acceptance.
